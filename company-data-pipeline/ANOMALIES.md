# Аномалии в review.csv

## Критическая аномалия
Файл review.csv не содержит отзывов. Его структура полностью повторяет таблицу компаний (id, name, category, city, address, rating, reviews_count, site, phone). Вместо отзывов там находятся записи о компаниях, частично пересекающиеся с основной выгрузкой. Вероятно, была перепутана выгрузка данных.

## Прочие аномалии
1. Некорректные рейтинги: "N/A", "4,5" (запятая), -3, 7.2 (вне 1–5), пустые значения.
2. Некорректные reviews_count: "много", -10, 45.5, пустые значения.
3. Опечатки в городах: "Санкат-Петербург", "Moscow", "москва", "Москва ".
4. Проблемы с кодировкой: искажённый текст (например, "РћРћРћ В«Р—Р°СЂСЏ РўРµС…В»").
5. Дубликаты ID: внутри файла есть повторяющиеся id (например, c_001049, c_001050, c_001075).
6. Некорректные сайты: "нет сайта", "https://" без домена, "htp://", одинаковый "shared-site.ru".
7. Некорректные телефоны: буквы в номере, неполный "+7", пустые.
8. Нестандартные ID: c_900006–c_900011 (не из основной выборки c_000xxx).
9. Пустые строки в конце файла.
10. Нарушение структуры строк: пропущен город, адрес смещён.
11. Несоответствие критериям: в задании упомянуты валидные email, но в данных нет поля email.

## Как обнаружены
- Вручную при просмотре CSV.
- Через SQL-запросы в Supabase (например, поиск по аномальным значениям).
- При сравнении с основной таблицей companies.
